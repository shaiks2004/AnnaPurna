## 2. Architectural Design & Constraints

1. **Enterprise Layout & App Router Structure**:
   - Every domain area has dedicated, shareable, deep-linkable Next.js App Router routes (`/commodities`, `/markets`, `/market-prices`, `/supplies`, `/lots`, `/requirements`).
   - `AppShell` provides responsive sidebar navigation, mobile drawer support, user profile display, active role badges, and safe logout action.
2. **Deterministic Baseline Matching Representation**:
   - In adherence to model governance and truth in advertising, the matching interface clearly discloses the matching engine version as `deterministic-baseline v1`.
   - Matching scores are displayed as normalized percentage indicators alongside multi-factor explanation tags (commodity match, location distance, grade/quality score, price proximity).
3. **Error Handling & Concurrency Conflict (409)**:
   - Centralized `ApiError` class safely extracts server error messages and validation error maps (`fieldErrors`).
   - Handles `409 Conflict` with code `CONCURRENT_UPDATE` by displaying user-actionable message: _"This record was changed by another user. Refresh before editing."_
4. **Zero Mock Domain Records**:
   - Production components render empty states (`No records found`) when backend tables are empty.
   - Seed credential helper is explicitly labeled on the login screen for developer guidance without hardcoded bypasses.
